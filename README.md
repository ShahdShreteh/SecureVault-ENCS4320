# SecureVault

## ENCS4320 – Applied Cryptography

SecureVault is a multi-user encrypted document exchange system designed to
allow users to securely store and share documents through an untrusted server.

The server stores the users' data and encrypted documents but must not be able
to read the contents of the documents.
